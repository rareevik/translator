# Simple translator with AI
This is a simple translator built with JavaScript and AI to translate messages. The goal is to learn how to express things in another language (in this initial project, only English is supported in v0) by starting with a message written in the user’s preferred language (Spanish, in my case). It provides a translation of what we want to say without translating the text too literally and potentially producing an incorrect result. 

## AI Model Provider
Initially, we’ll use OpenAI’s text API for translations in this project. If we find another provider or model that improves the speed and quality of the translations, we’ll switch to it later.

|Project Version|Provider|Model|Effort|
|---|---|---|---|
|V0|OpenAI|gpt-5.6-luna|Low|
